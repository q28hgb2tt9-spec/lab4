# Binary and Hexadecimal Number Converter (C++)

A C++ object-oriented application designed for numerical system conversions, specifically converting numbers between Decimal, Binary, and Hexadecimal formats. 

## Features
- **Object-Oriented Architecture:** Developed using structured header (`.h`) and source (`.cpp`) files, implementing custom classes for robust data handling.
- **Custom Exception Handling:** Includes a tailor-made `simpleException` class to handle runtime errors and validate input data.
- **Extensible Structure:** Features separate logical modules for binary and hexadecimal operations (`binary.cpp`, `hexadecimal.cpp`).

## Tech Stack
- **Language:** C++
- **Build System:** CMake (`CMakeLists.txt`)
